# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Report a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's **Private vulnerability reporting** feature on the repository's Security tab, or contact the repository owner privately through the address on their GitHub profile.

Include:

- the affected file or feature;
- steps to reproduce the issue safely;
- the possible impact;
- a suggested fix, if you have one.

Do not include real credentials, personal information, or data taken from a system without permission. You should receive an acknowledgement within seven days.

CyberNova Lab is an educational project. Please use test data and systems you own.
